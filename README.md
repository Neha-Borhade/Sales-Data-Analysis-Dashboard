# Sales Data Analysis Dashboard

## Project Overview
This project focuses on analyzing sales data using Microsoft Excel and creating an interactive dashboard to understand sales performance and business insights.

## Dashboard Preview

![Sales Dashboard](Sales_Dashboard.png)

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Excel Dashboard

## Key Features
- Monthly Sales Analysis
- Product-wise Sales Analysis
- Region-wise Sales Analysis
- Total Sales Calculation
- Total Profit Calculation
- Interactive Dashboard

## Project File
- `Sales_Data_Analysis.xlsm`

## Objective
To analyze sales data, identify sales trends, compare product and regional performance, and present meaningful insights through an Excel dashboard.
